# iluxaxa666
# Подсистема учета донорства и запасов крови медицинского центра

## Концепция системы
Веб-приложение для автоматизации работы центра переливания крови. Система позволяет вести учет доноров, отслеживать запасы крови по группам и резус-факторам, регистрировать донации и формировать заявки на выдачу крови для медицинских отделений. Цель — снизить риск нехватки критических групп крови и ускорить обработку данных о донорах.

## Технологический стек
- **Frontend:** React (JavaScript), React Router, Axios
- **Backend:** Node.js, Express
- **СУБД:** PostgreSQL
- **Аутентификация:** JWT (JSON Web Tokens)
- **Дополнительно:** Docker, Sequelize (ORM)

## Основной функционал
- Регистрация и ведение карточек доноров (ФИО, группа крови, резус-фактор, дата последней донации)
- Учет запасов крови (плазма, эритроциты, тромбоциты) по группам
- Оформление донации и автоматическое обновление запасов
- Формирование заявок от медицинских отделений
- Роли пользователей: администратор, врач, регистратор
