# iluxaxa666
# Подсистема учета донорства и запасов крови медицинского центра

## Концепция системы
Веб-приложение для автоматизации работы центра переливания крови. Система позволяет вести учет доноров, отслеживать запасы крови по группам и резус-факторам, регистрировать донации и формировать заявки на выдачу крови для медицинских отделений. Цель — снизить риск нехватки критических групп крови и ускорить обработку данных о донорах.

## Технологический стек
- **Frontend:** React (JavaScript), React Router, Axios
- **Backend:** Node.js, Express
- **СУБД:** PostgreSQL
- **Аутентификация:** JWT (JSON Web Tokens)
- **Дополнительно:** Docker, Sequelize (ORM)

## Основной функционал
- Регистрация и ведение карточек доноров (ФИО, группа крови, резус-фактор, дата последней донации)
- Учет запасов крови (плазма, эритроциты, тромбоциты) по группам
- Оформление донации и автоматическое обновление запасов
- Формирование заявок от медицинских отделений
- Роли пользователей: администратор, врач, регистратор

## Схема базы данных (основные таблицы)
- **donors** — доноры (id, ФИО, дата рождения, группа крови, резус-фактор, контакты)
- **donations** — донации (id, donor_id, дата, тип компонента, объем)
- **blood_stock** — запасы (id, группа крови, резус-фактор, компонент, количество)
- **requests** — заявки от отделений (id, отделение, группа крови, объем, статус)
- **users** — пользователи системы (id, логин, пароль-хэш, роль)

## Инструкции по развертыванию

### Требования
- Node.js (версия 18+)
- PostgreSQL (версия 14+)
- npm или yarn

### Установка и запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/wotblitznegativ-code/iluxaxa666.git
   cd iluxaxaxaxa
   ```

2. Установить зависимости бэкенда:
   ```bash
   cd server
   npm install
   ```

3. Установить зависимости фронтенда:
   ```bash
   cd ../client
   npm install
   ```

4. Скопировать `.env.example` в `.env` и заполнить своими данными:
   ```bash
   cp .env.example .env
   ```

5. Создать базу данных в PostgreSQL и применить миграции:
   ```bash
   cd ../server
   npx sequelize-cli db:create
   npx sequelize-cli db:migrate
   ```

6. Запустить бэкенд:
   ```bash
   npm run dev
   ```

7. Запустить фронтенд (в новом терминале):
   ```bash
   cd ../client
   npm start
   ```

8. Открыть в браузере: `http://localhost:3000`
